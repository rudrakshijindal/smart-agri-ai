# Smart Agriculture AI: Problem Statement

## Problem
Farmers often detect crop diseases late, guess when to irrigate, and have
no data-driven estimate of yield. This leads to crop loss and wasted water.

## Objectives
1. Build a CNN model that detects leaf diseases from images (target: 90%+ test accuracy).
2. Build a regression model that predicts crop yield per hectare.
3. Recommend irrigation using weather data and crop water requirements.
4. Show current weather and forecast for the user's location.
5. Combine everything in one easy-to-use web application.
